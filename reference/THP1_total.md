# THP-1 total proteome dataset.

Total proteome data from Schaefer et al. (2024). Infected condition:
THP-1 macrophages exposed to M. bovis BCG for 24 hours at a multiplicity
of 4.

## Usage

``` r
THP1_total
```

## Format

A data frame with 4,252 rows and 11 variables:

- Accession:

  UniProt accession numbers.

- Abundance Ratio (log2): (JMI) / (Control):

  The log2 transformed fold change of infected/control cells.

- Abundance Ratio Adj. P-Value: (JMI) / (Control):

  Calculated adjusted P value.

- Found in Sample: F1: Sample Control:

  Peak detection for each protein in sample F1.

- Found in Sample: F2: Sample Control:

  Peak detection for each protein in sample F2.

- Found in Sample: F3: Sample Control:

  Peak detection for each protein in sample F3.

- Found in Sample: F4: Sample JMI:

  Peak detection for each protein in sample F4.

- Found in Sample: F5: Sample JMI:

  Peak detection for each protein in sample F5.

- Found in Sample: F6: Sample JMI:

  Peak detection for each protein in sample F6.

- Found in Sample: F7: Sample JMI:

  Peak detection for each protein in sample F7.

- Found in Sample: F8: Sample JMI:

  Peak detection for each protein in sample F8.
