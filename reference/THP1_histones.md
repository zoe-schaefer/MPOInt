# THP-1 histone proteome dataset.

Histone proteome data from Schaefer et al. (2024). Infected condition:
THP-1 macrophages exposed to M. bovis BCG for 24 hours at a multiplicity
of 4.

## Usage

``` r
THP1_histones
```

## Format

A data frame with 215 rows and 11 variables:

- PTM:

  PTM descriptions.

- C1:

  C1 peptide abundances.

- I1:

  I1 peptide abundances.

- C2:

  C2 peptide abundances.

- I2:

  I2 peptide abundances.

- C3:

  C3 peptide abundances.

- I3:

  I3 peptide abundances.

- C4:

  C4 peptide abundances.

- I4:

  I4 peptide abundances.

- C5:

  C5 peptide abundances.

- I5:

  I5 peptide abundances.
