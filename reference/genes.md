# EpiFactors gene set.

Exported information from the EpiFactors database on epigenetic actors,
complexes, and targets.

## Usage

``` r
genes
```

## Format

A data frame with 801 rows and 7 variables:

- HGNC approved symbol:

  Common symbols for each member.

- UniProt ID (human):

  Corresponding UniProt IDs.

- Function:

  Assigned function.

- Modification:

  Resulting modification.

- Protein complex:

  Complex(es) with this effector as a member.

- Target entity:

  Modification or residue targeted by each complex.

- Product:

  Resulting modification or residue.
